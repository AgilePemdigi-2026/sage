Paket untuk [issue #30](https://github.com/AgilePemdigi-2026/sage/issues/30), dengan base `f5bfa178b76eacaf873d1ec64c74d3abddb0db76` pada `build/local-foundation`. Status: implementasi komponen tersedia; paket handoff diterapkan kembali di atas `main` setelah fondasi DATA-01 dan CCM digabung. Hasil verifikasi ulang dan review penerimaan dicatat pada PR. Ini bukan bukti integrasi fitur produk penuh.

## Scope

- `AppShell`: identitas SAGE, navigasi tiga layar, breadcrumb, skip link, fokus konten, dan layout mobile/desktop.
- `LoginPanel`: controlled props untuk idle/loading/denied/error/connected, dengan callback koneksi dan navigasi; tidak membuat session sendiri.
- `RepositoryPanel`: daftar terotorisasi, search/reset, input publik, pilihan branch, SHA opsional, validasi format, dan callback target. Branch hanya dipakai jika sumber branch cocok dengan repository dipilih; data target lama tidak boleh mengaktifkan submit.
- `ProgressPanel`: context repository/branch/full SHA/analysis ID, sembilan tahap, queued/running/failed/completed/limitations, retry, serta akses hasil yang menunggu callback integrasi.
- `/ui-preview`: fixture berlabel, pemilih skenario, dan callback lokal untuk memeriksa komponen. Tidak melakukan request GitHub/API produk, tidak menyimpan sesi, dan tidak membuat job/hasil nyata. Route memakai metadata noindex.

Komponen dan types ada di `apps/web/components/ui-foundation/`; fixture serta harness interaksi ada di `apps/web/app/ui-preview/`. CSS module membatasi styling ke shell. Dependency dan lockfile tidak berubah. `package.json` menambahkan unit test UI pada `npm test` dan script `test:ui`.

## Kontrak integrasi

Data masuk melalui discriminated union `LoadState<T>`; loading/error/empty berbeda dari ready. `onConnect`, `onResolveRepository`, `onSelectRepository`, `onRetry*`, dan `onSubmit` harus dihubungkan ke boundary aplikasi oleh pemilik integrasi. Jangan menyalin callback simulasi dari preview ke alur produk.

`normalizeRepository` dan `validateTarget` hanya memeriksa sintaks. Server tetap wajib memvalidasi session/izin, repository nyata, branch/history, target full SHA, dan idempotency sebelum membuat analysis. Branch props membawa nama repository agar response milik target lama tidak dipakai pada target baru. Handler submit menerima repository/branch/commit; `onTargetChange` memungkinkan integrator menghapus ringkasan lama ketika input berubah.

Saat daftar/branch gagal, komponen mempertahankan input lalu mengembalikan fokus ke search/branch sesudah retry berhasil. Navigasi memindahkan fokus ke konten; form salah memfokuskan field terkait. Loading/notice memakai status teks; kondisi gagal tidak hanya ditunjukkan warna. Native radio/select/input/button dipakai untuk keyboard. Animasi loading mengikuti prefers-reduced-motion.

Progres memakai enum pada API contract dan key tahap pada arsitektur. Tidak ada persentase/ETA buatan. Result action hanya aktif ketika status sukses dan `onOpenResult` tersedia; integrator wajib memberikan callback hasil terotorisasi. Retry nyata harus membuat analysis baru dengan full SHA/config yang sama sesuai kontrak API; preview hanya memperlihatkan contoh state dan ID.

## Verifikasi

Pengujian paket dijalankan pada Linux arm64, Node 24.22.0, npm 11.17.0, Next 16.4.2, dan Chromium bawaan image worker. Lint/typecheck, enam unit/integrity tests, production build, dan browser fixture diperiksa terpisah dari acceptance produk.

Command yang dapat diulang:

```sh
npm ci --include=dev
npm run db:generate
npm run check
npm run build
```

Untuk environment Docker setelah build/up:

```sh
docker compose exec -e BASE_URL=http://web:3000 -e UI_EVIDENCE_DIR=/app/storage/ui-01 worker npm run test:ui
```

Hasil serta screenshot baru ditulis ke `UI_EVIDENCE_DIR`; default lokal `artifacts/ui-01` diabaikan Git.

Hasil pengujian paket dan checksum source disertakan dalam arsip handoff. Pemeriksa berikutnya harus menambahkan tanggal, commit yang benar-benar diuji, platform, command, expected vs actual, temuan, serta bukti pengujian ulang pada issue/PR. ## Batas bukti

Visual mengikuti token lokal pada design guidelines: navy/teal, Inter/JetBrains Mono, radius dan spacing, UI Indonesia serta pendekatan mobile first. Akses Figma meminta autentikasi ulang saat paket disiapkan; kesetiaan pixel terhadap frame Figma belum diverifikasi. Pemeriksaan kontras otomatis hanya mencakup teks DOM yang terlihat pada state fixture, bukan audit aksesibilitas penuh atau evaluasi screen reader.

Tidak ada bukti login/izin GitHub, repository nyata, pipeline worker, graph, history/delete, dokumentasi/ekspor produk dari paket ini. Seluruh acceptance produk yang memerlukan integrasi tersebut tetap mengikuti test plan dan issue pemiliknya. ENV-01 evidence lama tetap catatan source fondasi pada waktunya; perubahan package script berikutnya tidak mengubah bukti historis itu.
