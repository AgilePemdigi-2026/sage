# Bahasa antarmuka

Gunakan bahasa Indonesia sehari-hari untuk penjelasan dan istilah Inggris yang umum bagi developer untuk kontrol serta konsep teknis. Jangan menerjemahkan istilah hanya agar seluruh halaman berbahasa Indonesia.

| Gunakan | Hindari dalam antarmuka |
| --- | --- |
| Error | Galat |
| Overview | Ikhtisar |
| Node, edge, graph | Simpul, tepi graf |
| Evidence | Pranala pembuktian |
| Entry point | Titik masuk ketika yang dimaksud endpoint/action kode |
| Proven / Indicated | Istilah yang menyiratkan kepastian runtime |
| Exact / Unresolved | Terbukti / belum terpecahkan untuk status resolver |
| Fit to view, zoom, reset | Terjemahan teknis yang sulit dikenali |

`Proven` berarti deklarasi atau hubungan statis memiliki evidence source. Ini tidak membuktikan suatu jalur pasti berjalan pada runtime. `Exact`/`Unresolved` tetap merupakan status resolver yang terpisah.

Label dari source atau koreksi pengguna harus dipertahankan apa adanya. Jangan mengganti teks milik repository target dengan kamus UI, atau mengubah identifier/API/schema untuk kepentingan bahasa. Penjelasan, pesan validasi dan petunjuk boleh tetap dalam bahasa Indonesia yang ringkas.
