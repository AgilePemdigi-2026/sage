# Logo teknologi

Logo berasal dari [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons), memakai varian `original` untuk Next.js, React, TypeScript, Tailwind CSS, Node.js, PHP, PostgreSQL, Prisma, Docker, dan Playwright. Lisensi sumber tersedia pada [LICENSE.devicon.txt](LICENSE.devicon.txt). Logo Prisma diberi alas putih agar terbaca pada tema terang/gelap; bentuk mereknya dipertahankan.

Nama dan logo merek mengikuti pemilik masing-masing. File SVG disimpan lokal agar tampilan README tidak bergantung pada layanan badge atau CDN saat dibuka.
