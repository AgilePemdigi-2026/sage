# Operations

[Runbook Coolify](COOLIFY.md) mencakup deployment, resource pada server bersama, environment privat, verifikasi release, backup manual ke laptop, dan pemulihan pada volume terpisah. Ini panduan operator; perubahan dokumentasi tidak melakukan deployment.

Domain aplikasi: [sage.caiis.ai.id](https://sage.caiis.ai.id/). Pemeriksaan health hanya membuktikan respons web/database saat diperiksa. Catatan rollout bertanggal berada di [arsip operasi](../archive/operations/); jangan gunakan digest atau status historis sebagai release terbaru tanpa memeriksa ulang.
